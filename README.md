# 원 그리기 정확도 게임

사용자가 캔버스에 원을 그리면 완벽한 원과 얼마나 가까운지 정확도(0~100점)를
계산해 보여주는 웹 게임입니다. 명예의 전당(랭킹)과 시상대, 결과 저장 기능을
갖춘 단일 기기용 로컬 웹 앱입니다.

## 실행 방법

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

서버가 실행되면 같은 PC의 브라우저에서 `http://127.0.0.1:5000` 으로 접속합니다.

## 게임 흐름

1. **메인** — 타이틀과 `시작하기` / `명예의 전당` 버튼
2. **명예의 전당** — 왼쪽에 시상대(1~3등, 폭죽 애니메이션 포함),
   오른쪽에 전체 순위표
3. **등록** — 명예의 전당에 올리고 싶다면 체크 후 닉네임 입력
   (체크하지 않으면 점수만 보고 저장은 하지 않음)
4. **그리기** — 20초 제한 시간 안에 원을 한 번에 그리기
   (스트로크를 끝내거나 시간이 다 되면 종료)
5. **결과** — 정확도 점수, 완벽한 원을 반투명(30%)으로 오버레이, 정확도별 멘트

## 정확도 멘트 구간

점수는 소수 셋째 자리까지 계산되며 화면에는 둘째 자리까지 표시됩니다.
멘트는 10점 단위로 나뉩니다.

| 정확도 | 멘트 |
|---|---|
| 90~100 | 당신은 컴퍼스인가요?! |
| 80~90  | 거의 완벽해요, 놀라운 솜씨! |
| 70~80  | 아주 동그랗네요! |
| 60~70  | 꽤 동그래요! |
| 50~60  | 제법 원에 가까워요 |
| 40~50  | 음, 원의 느낌은 나요 |
| 30~40  | 원이라고 우길 수는 있어요 |
| 20~30  | 살짝 많이 찌그러졌어요 |
| 10~20  | 이건... 감자인가요? |
| 0~10   | 이것은... 추상화인가요? |

## 데이터 저장

모든 제출 기록은 `data/leaderboard.csv` 에 UTF-8(BOM 포함)로 저장됩니다.
한국어 Windows 환경의 Excel에서도 깨짐 없이 열립니다.

기록은 명예의 전당에 등록을 선택한 경우에만 저장되며, 제출된 순서대로 누적됩니다.

| 컬럼 | 설명 |
|---|---|
| `id`        | 고유 식별자 (UUID) |
| `timestamp` | 제출 시각 (ISO 8601) |
| `nickname`  | 닉네임 |
| `accuracy`  | 정확도 점수 (0~100) |
| `points`    | 그린 원의 정규화된 좌표 배열 (JSON) |

기존 컬럼 구성이 다른 CSV가 있으면 서버 시작 시 자동으로 마이그레이션됩니다.
