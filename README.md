# 원 그리기 정확도 게임

사용자가 캔버스에 원을 그리면 완벽한 원과 얼마나 가까운지 정확도(0~100점)를
계산해 보여주는 단일 기기용 로컬 웹 앱입니다. 명예의 전당(랭킹)과 시상대,
실시간 통계, 결과 미리보기 데모 애니메이션을 제공합니다.

## 실행 방법

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

서버가 실행되면 같은 PC의 브라우저에서 `http://127.0.0.1:5000` 으로 접속합니다.

## 게임 흐름

1. **메인** — 두 단으로 구성됩니다.
   - 왼쪽: 결과 화면 미리보기 데모. 손그림 같은 파란 원이 그려지고
     기준 원과 점수가 페이드 인 되는 6초 루프 애니메이션이 재생됩니다.
   - 오른쪽: 타이틀, 통계 스트립(`총 기록` / `최고 점수` / `오늘 최고`),
     `시작하기` / `명예의 전당` 버튼.
2. **명예의 전당** — 왼쪽 다크 카드에 1~3등 시상대(폭죽 애니메이션 포함),
   오른쪽에 1위부터 마지막까지 전체 순위표.
3. **등록** — 명예의 전당에 올리고 싶다면 체크 후 닉네임 입력.
   체크하지 않으면 점수만 확인하고 저장하지 않습니다.
4. **그리기** — 20초 제한 시간 안에 원을 한 번에 그립니다(스트로크 종료
   또는 타임아웃 시 종료). 그린 원이 너무 작으면 "원이 충분히 크지 않습니다.
   다시 그려주세요." 안내 후 타이머가 초기화되어 다시 도전합니다.
5. **결과** — 정확도 점수(소수 둘째 자리까지 표시) · 정확도별 멘트 · 등록한
   경우 전체 순위 표시. 그린 원 위에 **최소제곱 최적 원**(Kåsa fit)을 반투명
   30%로 오버레이해 얼마나 가까웠는지 한눈에 비교할 수 있습니다.

화면 오른쪽 아래에는 실시간 시계가 `YYYY-MM-DD HH:MM:SS` 형식으로 표시됩니다.

## 정확도 멘트 구간

점수는 소수 셋째 자리까지 계산되며 화면에는 둘째 자리까지 표시됩니다.
멘트는 10점 단위로 나뉩니다.

| 정확도 | 멘트 |
|---|---|
| 90~100 | 당신은 컴퍼스인가요?! |
| 80~90  | 거의 완벽해요, 놀라운 솜씨! |
| 70~80  | 아주 동그랗네요! |
| 60~70  | 꽤 동그래요! |
| 50~60  | 제법 원에 가까워요 |
| 40~50  | 음, 원의 느낌은 나요 |
| 30~40  | 원이라고 우길 수는 있어요 |
| 20~30  | 살짝 많이 찌그러졌어요 |
| 10~20  | 이건... 감자인가요? |
| 0~10   | 이것은... 추상화인가요? |

## 정확도 계산 방식

- 그려진 점들에 **최소제곱 원 피팅(Kåsa)** 을 적용해 중심(`cx`, `cy`)과
  반지름 `r` 을 구합니다. 결과 화면의 기준 원도 이 값을 그대로 사용합니다.
- 세 가지 지표를 가중 합산해 0~100점으로 변환합니다.
  - `roundness` (가중치 0.6): 반지름의 변동계수 `cv = stddev/r_mean` 를
    `1 - cv / 0.45` 로 매핑. 값이 작을수록 원에 가깝습니다.
  - `closure` (가중치 0.2): 첫 점과 끝 점 사이의 간격이 작을수록 가깝게
    닫혔다고 봅니다.
  - `coverage` (가중치 0.2): 중심을 기준으로 한 바퀴를 다 돌았는지(부분
    호로 끝내지 않았는지) 평가합니다.

## 데이터 저장

모든 제출 기록은 `data/leaderboard.csv` 에 UTF-8(BOM 포함)로 저장됩니다.
한국어 Windows 환경의 Excel에서도 깨짐 없이 열립니다.

기록은 명예의 전당에 등록을 선택한 경우에만 저장되며, 제출된 순서대로 누적됩니다.

| 컬럼 | 설명 |
|---|---|
| `id`        | 고유 식별자 (UUID) |
| `timestamp` | 제출 시각 (ISO 8601) |
| `nickname`  | 닉네임 |
| `accuracy`  | 정확도 점수 (0~100, 소수 셋째 자리까지) |
| `points`    | 그린 원의 정규화된 좌표 배열 (JSON, 최대 200점으로 다운샘플) |

기존 컬럼 구성이 다른 CSV가 있으면 서버 시작 시 자동으로 마이그레이션됩니다.

## API

| 메서드 | 경로 | 설명 |
|---|---|---|
| `GET`  | `/` | SPA 페이지 |
| `GET`  | `/api/leaderboard` | 전체 기록을 점수 내림차순으로 반환. 상위 3등은 썸네일용 정규화 좌표 포함 |
| `GET`  | `/api/stats` | `count`, `best`, `today_best` 집계 |
| `POST` | `/api/submit` | 점수 계산 후 등록 옵션에 따라 CSV 저장. `accuracy`, `comment`, `circle`, `rank` 등을 반환 |
