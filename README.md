# 원 그리기 정확도 게임

사용자가 캔버스에 원을 그리면 완벽한 원과 얼마나 가까운지 정확도(0~100점)를
계산해 보여주는 웹 게임입니다. 명예의 전당(랭킹)과 시상대, 결과 저장 기능을
갖추고 있으며, 여러 기기가 동시에 접속해 플레이할 수 있습니다.

## 실행 방법

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

서버가 `http://0.0.0.0:5000` 에서 실행됩니다.

- 같은 PC에서 플레이: 브라우저로 `http://127.0.0.1:5000` 접속
- 다른 기기에서 플레이: 서버 PC와 같은 네트워크에 연결한 뒤
  `http://<서버PC_IP>:5000` 으로 접속 (예: `http://192.168.0.10:5000`)

여러 기기가 동시에 접속해 게임을 진행할 수 있으며, 제출되는 결과는
서버에서 동시에 처리되어 하나의 CSV 파일에 안전하게 누적됩니다
(`threading.Lock` 으로 동시 쓰기 보호).

## 게임 흐름

1. **메인** — 타이틀과 `시작` / `명예의 전당` / `관리자` 버튼
2. **명예의 전당** — 왼쪽 50%에 시상대(1~3등, 폭죽 애니메이션 포함),
   오른쪽 50%에 전체 순위표
3. **닉네임 입력** — 닉네임 입력. 상품 수령 동의 체크 시 개인정보 수집·이용
   동의서가 펼쳐지고, "위 사항에 동의하시겠습니까?" 체크 + 연락처 입력을 모두
   완료해야 다음 단계로 진행
4. **그리기** — 20초 제한 시간 안에 원을 한 번에 그리기
   (스트로크를 끝내거나 시간이 다 되면 종료)
5. **결과** — 정확도 점수, 완벽한 원을 반투명(30%)으로 오버레이, 정확도별 멘트

## 관리자 모드

메인 화면의 `관리자` 버튼으로 진입합니다. 암호 `0326` 을 입력하면 모든 기록을
조회·수정·삭제할 수 있습니다. (암호는 `app.py` 의 `ADMIN_PASSWORD` 상수에서
변경 가능합니다.)

## 정확도 멘트 구간

| 정확도 | 멘트 |
|---|---|
| 80~100 | 당신은 컴퍼스인가요?! |
| 70~80  | 거의 완벽해요, 놀라운 솜씨! |
| 50~70  | 꽤 동그랗네요! |
| 30~50  | 음... 원의 형태는 갖췄어요 |
| 0~30   | 이것은... 추상화인가요? |

## 데이터 저장

모든 제출 기록은 `data/leaderboard.csv` 에 UTF-8(BOM 포함)로 저장됩니다.
한국어 Windows 환경의 Excel에서도 깨짐 없이 열립니다.

| 컬럼 | 설명 |
|---|---|
| `id`        | 고유 식별자 (UUID, 관리자 수정·삭제에 사용) |
| `timestamp` | 제출 시각 (ISO 8601) |
| `nickname`  | 닉네임 |
| `accuracy`  | 정확도 점수 (0~100) |
| `consent`   | 상품 수령 동의 여부 (1/0) |
| `contact`   | 연락처 (동의한 경우에만) |
| `points`    | 그린 원의 정규화된 좌표 배열 (JSON) |

기존에 `id` 컬럼이 없는 CSV가 있으면 서버 시작 시 자동으로 마이그레이션됩니다.
